# Changelog

## [1.0.0]

First release.

- Point the camera at text, freeze the frame, select exact characters, copy.
- Fully offline: on-device ML Kit text recognition (Latin), no network permission.
- Own selection UI with Copy as the only action: no web search, no Lens.
- Long-press or double-tap selects a word; drag the handles, with a magnifier while dragging.
- Pinch to zoom, one-finger pan when zoomed.
- Text areas stay bright, the rest is dimmed; highlighter-style selection.
